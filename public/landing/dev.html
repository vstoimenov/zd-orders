ordyx

Ordyx за програмисти

Собствен сайт се свързва с Ordyx по три начина, които се комбинират: изборът на офис/автомат в неговата форма (без код), API за поръчки с ключ и уебхуци за товарителниците. За WooCommerce има готов плъгин.

1. Избор на офис във формата2. Ключ3. Поръчки4. Уебхуци5. Грешки и лимити

1. Изборът на офис във вашата форма

Един скрипт и един div с указание кои полета да попълни. Клиентът търси офис или автомат на Еконт, Спиди или BOX NOW, вижда най-близките с „Намери ме“, карта и работно време; избраното се записва във вашите полета.

<script src="https://app.ordyx.eu/checkout.js" defer></script>

<select id="how" name="delivery_type">
  <option value="econt_office">Еконт – офис / автомат</option>
  <option value="speedy_office">Спиди – офис / автомат</option>
  <option value="speedy_address">Спиди – до адрес</option>
</select>
<div data-ordyx-picker data-type="select:#how"
     data-into="#office" data-city="#city" data-zip="#zip" data-office-id="#office_id"></div>
<input id="office" name="office_text" readonly>
<input id="city" name="city"> <input id="zip" name="post_code">
<input type="hidden" id="office_id" name="office_id">
АтрибутКакво прави
data-typeФиксиран тип (econt_office, speedy_office, boxnow_locker, speedy_address) или select:#id — следва избора в този <select>, чиито стойности са същите типове.
data-intoПолето за текста на избора, напр. „ЕКОНТ – офис Плевен Център (1127), ул. Левски 5“. Изпратете го като office_text.
data-city, data-zipГрад и пощенски код на офиса (или въведените при адрес).
data-office-idИдентификаторът на офиса, напр. econt:1127. Изпратете го като office_id — така товарителницата се прави без преписване.
data-hostПо желание: домейнът на магазина, ако формата е на друг домейн (решава дали BOX NOW е включен).

С JavaScript: OrdyxPicker.mount(el, { type, onChange }) връща { value(), setType(type), destroy() }; onChange получава { type, officeId, officeText, city, postCode, addressText, error }.

2. Ключът на магазина

В Ordyx → Интеграции → WooCommerce → „Направи ключ“. Показва се веднъж; нов ключ спира стария. Пазете го само на сървъра — никога в браузъра.

curl https://app.ordyx.eu/api/orders \
  -H "Authorization: Bearer ordyx_live_…"
# → {"ok":true,"shop":{"name":"Моят магазин","domain":"moiat-magazin.bg"}}

3. Поръчки

Изпращайте поръчката от сървъра, след като е приета (при наложен платеж веднага; при карта — след успешно плащане, с "paid": true).

POST https://app.ordyx.eu/api/orders
Authorization: Bearer ordyx_live_…
Content-Type: application/json
X-Ordyx-Site: {"webhookUrl":"https://moiat-magazin.bg/ordyx-webhook"}

{
  "source": "api",
  "external_id": "10452",
  "name": "Мария Иванова",
  "phone": "0888 123 456",
  "email": "maria@example.bg",
  "delivery_type": "econt_office",
  "office_id": "econt:1127",
  "office_text": "ЕКОНТ – офис Плевен Център (1127), ул. Левски 5",
  "city": "Плевен",
  "post_code": "5800",
  "address_text": "",
  "items": [{ "name": "Тениска — M, черна", "qty": 2, "price": 15.00, "sku": "T-M-B" }],
  "total": 34.40,
  "currency": "EUR",
  "payment_method": "cod",
  "paid": false
}
ПолеЗначение
external_idНомерът на поръчката при вас (до 40 знака). Същият номер втори път обновява поръчката, докато няма товарителница — никога дубликат.
delivery_typeecont_office, econt_address, speedy_office, speedy_address, boxnow_locker или other (куриерът се избира в Ordyx при товарителницата).
office_id, office_textОт избора на офис. При адрес: city + address_text (+ post_code).
items[].priceЦената, която клиентът плаща за брой (с ДДС). Доставката е в total.
payment_method, paidcod = наложен платеж (сумата се събира от куриера). Всичко друго + paid: true = платена, товарителницата е без наложен платеж. Поръчка с карта изпращайте чак когато е платена.

Отговор: {"ok":true,"inserted":true,"updated":false,"locked":false}. locked: true = вече има товарителница и промяната не е приложена.

Отказ

{ "source": "api", "external_id": "10452", "status": "cancelled" }

Преди товарителница поръчката се отказва (и наличността се връща); след товарителница Ordyx я пази и известява магазина.

PHP

$ch = curl_init('https://app.ordyx.eu/api/orders');
curl_setopt_array($ch, [
  CURLOPT_POST => true, CURLOPT_RETURNTRANSFER => true, CURLOPT_TIMEOUT => 8,
  CURLOPT_HTTPHEADER => ['Authorization: Bearer ' . ORDYX_KEY, 'Content-Type: application/json',
    'X-Ordyx-Site: ' . json_encode(['webhookUrl' => 'https://moiat-magazin.bg/ordyx-webhook'])],
  CURLOPT_POSTFIELDS => json_encode($order, JSON_UNESCAPED_UNICODE),
]);
$answer = json_decode(curl_exec($ch), true);

Node.js

const r = await fetch('https://app.ordyx.eu/api/orders', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.ORDYX_KEY}`, 'Content-Type': 'application/json',
    'X-Ordyx-Site': JSON.stringify({ webhookUrl: 'https://moiat-magazin.bg/ordyx-webhook' }) },
  body: JSON.stringify(order),
});
const answer = await r.json();
Ако Ordyx не отговори (мрежа, време над 8 с), запазете поръчката при вас и опитайте пак по-късно със същия external_id — повторното изпращане е безопасно.

4. Уебхуци

Дайте адрес в X-Ordyx-Site (webhookUrl, https, на домейна на магазина). Ordyx праща POST там, когато направи товарителница, анулира я или откаже поръчката:

POST https://moiat-magazin.bg/ordyx-webhook
X-Ordyx-Timestamp: 1792700000
X-Ordyx-Signature: 3f1a…   (HMAC-SHA256 с ключа над "timestamp.body", hex)

{ "api": 1, "event": "shipped", "externalId": "10452",
  "number": "1055278971773", "courier": "econt", "courierName": "Еконт",
  "trackUrl": "https://www.econt.com/services/track-shipment/1055278971773",
  "trackingPage": "https://app.ordyx.eu/p/…" }
eventКакво да направите
shippedЗапишете номера и покажете trackingPage на клиента (страница „Моята поръчка“ с етапи и офиса).
waybill_cancelledТоварителницата е анулирана — махнете номера.
cancelledПоръчката е отказана в Ordyx или от клиента.

Проверка на подписа (PHP): hash_equals(hash_hmac('sha256', $ts . '.' . $rawBody, ORDYX_KEY), $sig), като |now − ts| ≤ 300 s. Отговорете с 2xx; при друго Ordyx опитва отново през нощта до 3 дни. Пренасочвания не се следват.

5. Грешки и лимити

КодЗначение
400Невалидна поръчка — error казва какво (напр. office required, address required, external_id required).
401Невалиден или сменен ключ.
403Магазинът още чака одобрение в Ordyx.
409Номерът е зает от поръчка на друг източник.
429Над 600 заявки на час с този ключ.

Офисите и автоматите (за собствен избор на офис): GET https://app.ordyx.eu/api/offices?courier=econt|speedy|boxnow — публично, кеширано.
