# BOX NOW Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** BOX NOW lockers in the checkout (phase A) and BOX NOW waybills per shop (phase B).

**Architecture:** BOX NOW is a third courier next to Econt/Speedy: lockers live in `zd.offices` (`courier='boxnow'`),
orders use `delivery_type='boxnow_locker'`, waybills go through the shared `COURIERS` map in `lib/waybills.js` with a new
adapter `lib/boxnow-api.js`. No new Vercel functions (10/12 used).

**Tech Stack:** Node 22 ESM, Postgres (`zd` schema), node:test + PGlite, ES5 checkout widget, vanilla admin HTML.

**Spec:** `docs/superpowers/specs/2026-10-20-boxnow-design.md`

## Global Constraints
- Office id `boxnow:<locker id>`; courier key `boxnow`; delivery type `boxnow_locker` (≤ 20 chars, `lib/order.js` limit).
- Hosts: stage `https://api-stage.boxnow.bg`, live `https://api-production.boxnow.bg`; paths `/api/v1/...`; auth `POST /api/v1/auth-sessions` `{grant_type:'client_credentials', client_id, client_secret}` → Bearer, `expires_in` 3600.
- Locker list: `https://locationapi-production.boxnow.bg/v1/apms_bg-BG.json` → `{data:[{id,addressLine1,addressLine2,postalCode,name,state,...}]}`.
- Phones to BOX NOW in `+359…` form; COD amount in (0, 5000); compartment size 1|2|3 required for any-apm origin.
- Bulgarian user-facing messages; English code/commits with trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never touch Econt/Speedy behaviour; all existing tests stay green.
- Production migration applied by hand (Supabase MCP) before deploy.

## Review Focus
1. Test mode must only ever call the stage host (a live parcel by mistake costs money).
2. An unclear BOX NOW answer on create (timeout, 5xx, odd body) must leave the order `unknown`, never free it for a second parcel.
3. A failed locker download must never wipe the cached lockers (minRatio) nor fail the Econt refresh.
4. A CB page offering both Econt and BOX NOW must show both choices in the widget.
5. COD orders send `paymentMode:'cod'` with the order total; prepaid orders send `prepaid` and `"0.00"`.
